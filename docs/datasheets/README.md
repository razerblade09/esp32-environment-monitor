# Datasheets

Place component datasheets here for reference during footprint assignment, PCB layout, and hardware bring-up.

## Required Before Footprint Assignment

| Component | Datasheet Needed For |
|---|---|
| PMS5003 | Verify SET and RESET pin operating states; connector pinout and dimensions |
| SCD40 | Verify unused pin requirements; LGA package footprint |
| SGP40 | DFN package footprint verification |
| BME280 | LGA package footprint verification |
| SSD1306 | Confirm physical module connector type and dimensions |
| AMS1117-3.3 | Confirm SOT-223 footprint; validate thermal performance |
| ESP32-WROOM-32 | Antenna keepout requirements; module pad dimensions |

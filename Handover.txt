# 1. Project Overview

The project is an ESP32-based environmental monitoring device designed to measure and display multiple environmental parameters using dedicated sensors.

The system uses an ESP32-WROOM-32 bare module as its main microcontroller. It collects data from particulate matter, VOC, temperature, humidity, pressure, and CO₂ sensors.

The collected measurements will eventually be processed by the ESP32 and displayed through an OLED interface.

The goal is to develop a custom electronic device, beginning with a complete schematic in KiCad and progressing toward a manufacturable PCB.

## 3. System Communication Architecture

The system uses two communication interfaces.

### I²C Communication

The following devices share the same I²C bus:

- SGP40
- BME280
- SCD40
- SSD1306 OLED

ESP32 connections:

| ESP32 GPIO | Signal |
|---|---|
| GPIO21 | I2C_SDA |
| GPIO22 | I2C_SCL |

BME280 address selection:
- SDO connected to GND.
- Intended I²C address: 0x76.

### UART Communication

The PMS5003 communicates with the ESP32 using UART2.

| Device | Connection |
|---|---|
| PMS5003 TX | ESP32 GPIO16 |
| PMS5003 RX | ESP32 GPIO17 |

Net labels:
- PMS_RX
- PMS_TX

Note: These labels represent the ESP32-side signal names. GPIO16 receives PMS5003 TX, while GPIO17 transmits to PMS5003 RX.

## 4. Schematic Connections

### 4.1 ESP32-WROOM-32

The project uses the bare ESP32-WROOM-32 module, not an ESP32 development board.

Power:
- VDD → +3V3
- GND → GND

Boot and reset:
- EN → 10kΩ pull-up to +3V3
- GPIO0 → 10kΩ pull-up to +3V3
- RESET pushbutton connects EN to GND
- BOOT pushbutton connects GPIO0 to GND

Decoupling:
- 100nF capacitor between +3V3 and GND
- 10µF capacitor between +3V3 and GND

Communication:
- GPIO21 → I2C_SDA
- GPIO22 → I2C_SCL
- GPIO16 → PMS_RX
- GPIO17 → PMS_TX

GPIO2 is marked as not connected.

## 5. Power Supply Design

The current schematic contains an AMS1117-3.3 regulator.

Connections:

| Regulator Pin | Connection |
|---|---|
| VIN (Pin 3) | +5V |
| GND (Pin 1) | GND |
| VOUT (Pin 2) | +3V3 |

Capacitors:
- C1: 10µF between +5V and GND.
- C2: 22µF tantalum between +3V3 and GND (AMS1117 output capacitor requirement; set the value field in the schematic).
- C5: 1µF on SGP40 VDDH. Input connector J2 (5V_IN). I²C pull-ups R3/R4 4.7kΩ to +3V3.

PWR_FLAG symbols were added to resolve KiCad power ERC checks.

### Important Engineering Review

The AMS1117-3.3 has not yet been validated for the complete system's current requirements.

Before PCB fabrication:
1. Calculate the total current consumption.
2. Account for ESP32 Wi-Fi transmission current peaks.
3. Check the regulator's dropout voltage.
4. Calculate regulator power dissipation and temperature.
5. Confirm that the selected regulator and PCB copper area can safely handle the load.

Do not assume the AMS1117 is adequate simply because the schematic passes ERC.

## 6. ESP32 Programming Interface

A four-pin USB-UART programming header was included.

| Header Pin | Connection |
|---|---|
| 1 | GND |
| 2 | GPIO3 / U0RXD |
| 3 | GPIO1 / U0TXD |
| 4 | No Connect |

The programming interface requires a USB-UART adapter with 3.3V logic levels.

The external adapter's power output must not be connected to the board's power supply through this header.

### Phase 2 — Schematic Engineering Review
1. Verify PMS5003 SET and RESET operating states.
2. Verify SCD40 unused pin requirements.

2. Define board dimensions and shape.

3. Generate Gerber files.

2. Check for short circuits.
3. Verify 5V and 3.3V rails.
4. Test ESP32 programming.
5. Test each sensor individually.
6. Test the complete I²C bus.
7. Test PMS5003 UART communication.
8. Validate sensor readings.
